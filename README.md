# CityKart GM Visibility — Online Edition

Read **DEPLOY_ON_STREAMLIT.md** for updating your existing Streamlit app.

Entrypoint: **app.py**. Recommended Python version: **3.12**.

Install dependencies from **requirements.txt** and include all template folders in your GitHub repository. This edition generates XLSX reports on Linux without Microsoft Excel. It retains the latest report rules and exports a value-only three-sheet management summary.
